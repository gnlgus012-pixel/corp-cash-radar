# 법인 자금 레이더

DART 공시·재무 + 뉴스(네이버 키가 있으면 네이버, 없으면 구글 뉴스) + 한국은행 금리를 매일 아침 자동 수집해
**법인 자금 동향 / 여유자금 법인 / 추천 상품 / 주요 이슈**를 한 화면에 보여주는 대시보드입니다.

- 서버 없음: GitHub Actions가 매일 수집 → GitHub Pages가 화면 게시
- 비용 없음: 모든 API·GitHub 기능 무료 범위
- 처음 올리면 **샘플 데이터(가상 법인)** 로 화면이 보이고, 첫 수집 후 실제 데이터로 바뀝니다.

> ⚠️ **GitHub Pages 사이트는 주소만 알면 누구나 볼 수 있습니다.**
> 원천은 공개 데이터라도 "여유자금 법인 랭킹·추천 상품"은 영업 전략 정보입니다.
> 사내 정보보호 정책 확인 후 사용하고, 고객 잔고 등 사내 데이터는 절대 올리지 마세요.

## 폴더 구조

```
corp-cash-radar/
├─ .github/workflows/daily.yml   매일 07시 자동 실행 설정
├─ scripts/collect.py            수집·점수 계산 스크립트
├─ config/
│   ├─ config.json               이벤트 분류 규칙, 점수 가중치, 뉴스 키워드, 금리 코드
│   ├─ products.json             자금 성격별 추천 상품 (사내 상품명으로 교체)
│   └─ watchlist.csv             관심법인 (항상 분석 대상에 포함)
├─ docs/
│   ├─ index.html                대시보드 화면
│   └─ data/data.json            수집 결과 (자동 갱신)
└─ requirements.txt
```

## 설치 (약 20분)

### 1. API 키 발급
| 키 | 발급처 | 필수 |
|---|---|---|
| DART | opendart.fss.or.kr → 인증키 신청 | 필수 |
| 네이버 뉴스 | developers.naver.com → 애플리케이션 등록 → **검색** API 선택 | 선택 (없으면 구글 뉴스 사용) |
| 한국은행 | ecos.bok.or.kr → Open API → 인증키 신청 | 선택 |

### 2. 저장소 만들고 파일 올리기
1. GitHub 로그인 → 우측 상단 `+` → **New repository**
2. 이름 입력 (예: `corp-cash-radar`) → **Public** → Create
   - 무료 계정에서 Pages는 Public 저장소만 가능 (Private는 유료 요금제 필요 — 요금제 확인)
3. **uploading an existing file** 클릭 → 이 폴더 안의 파일·폴더를 전부 끌어다 놓기 → Commit
   - `.github` 폴더는 숨김 폴더라 끌어다 놓기가 안 될 수 있음 → 아래 "문제 해결" 참고

### 3. API 키 등록 (Secrets)
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
|---|---|
| `DART_API_KEY` | DART 인증키 |
| `NAVER_CLIENT_ID` | 네이버 Client ID |
| `NAVER_CLIENT_SECRET` | 네이버 Client Secret |
| `ECOS_API_KEY` | 한국은행 인증키 |

### 4. Pages 켜기
**Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / 폴더: `/docs` → Save
→ 1~2분 뒤 `https://아이디.github.io/corp-cash-radar/` 접속

### 5. 첫 수집 실행
**Actions** 탭 → (처음이면 "I understand… enable" 클릭) → `법인 자금 레이더 데이터 갱신` → **Run workflow**
- 첫 실행은 최근 30일 공시 + 재무 최대 100개사만 수집합니다.
- 이후 실행마다 과거 공시를 30일씩 더 채워 90일까지 늘리고, 남은 재무도 이어서 수집합니다 (3회 실행이면 90일 완성).
- 한 번 실행이 40분을 넘으면 그때까지 모은 것만 저장하고 정상 종료하며, 다음 실행이 이어서 수집합니다.
- 평일 07시에 자동 실행됩니다.

### 6. 휴대폰 홈 화면에 추가
- 아이폰: Safari로 접속 → 공유 → **홈 화면에 추가**
- 안드로이드: Chrome으로 접속 → ⋮ → **홈 화면에 추가**

## 계산 방식

**여유자금 점수 (100점)**
| 항목 | 배점 | 계산 |
|---|---|---|
| 순현금 | 40 | (현금및현금성자산 + 단기금융상품 − 차입금·사채) 분석 대상 내 백분위 |
| 현금/자산 | 20 | (현금및현금성자산 + 단기금융상품) ÷ 자산총계, 백분위 |
| 현금 증감 | 20 | 현금및현금성자산 전기말 대비 증감률, 백분위 |
| 유입 공시 | 20 | 최근 90일 서로 다른 유입 유형 1개당 10점 |

**자금 성격 분류**
- 최근 90일 유입 공시 → 단기 집행대기
- 순현금 > 0, 현금/자산 ≥ 15% → 구조적 여유자금
- 순현금 > 0 → 중기 운용
- 그 외 → 모니터링

## 한계 · 확인 필요 사항

- **구글 뉴스 RSS는 공식 API가 아닙니다.** 예고 없이 형식이 바뀌거나 막힐 수 있으며, 그 경우 경고만 표시되고 나머지는 정상 동작합니다. 안정적으로 쓰려면 네이버 키를 등록하세요.

- **재무 시차**: 분기·반기 보고서 기준이라 최대 수개월 전 숫자입니다. 화면에 기준 보고서(예: 2026 반기)를 표시합니다.
- **차입금은 근사치**: 계정명에 "차입금"·"사채"가 들어간 재무상태표 항목을 합산합니다. 회사마다 계정 구성이 달라 소계 중복 등 오차가 있을 수 있으니 상세 화면의 DART 원문으로 확인하세요.
- **재무 커버리지**: 기본 설정은 유가·코스닥 상장사만 재무를 수집합니다. 비상장사 재무가 API로 얼마나 제공되는지는 실제 호출로 확인이 필요합니다.
- **금액 미표시**: 공시 이벤트의 조달·매각 금액은 아직 수집하지 않습니다(공시 유형별 상세 API 필드 확인 후 추가 예정). 공시 원문 링크로 확인하세요.
- **금리 통계코드**: `config.json`의 ECOS 코드는 사용 전 ECOS 통계코드검색에서 확인이 필요합니다. 틀린 항목은 화면에서 자동으로 빠지고 경고에 표시됩니다.
- **해외 서버 실행**: Actions는 해외에서 실행됩니다. DART가 해당 IP를 막으면 실행 로그에 `접근 불가 IP(012)`가 표시됩니다.
- 추천 상품은 **내부 영업 참고용**이며, 실제 권유 시 적합성·적정성 원칙을 따라야 합니다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| `.github` 폴더가 안 올라감 | 저장소에서 **Add file → Create new file** → 파일명에 `.github/workflows/daily.yml` 입력 → 내용 붙여넣기 |
| 실행이 빨간색(실패) | Actions → 해당 실행 → `데이터 수집` 단계 로그 확인. `인증키 오류`면 Secrets 이름·값 확인 |
| 화면이 안 바뀜 | 실행 성공 후 1~2분 대기, 새로고침. 계속 안 바뀌면 Settings → Pages 설정 확인 |
| 화면 상단에 경고 표시 | 일부 데이터 수집 실패 내용 — 키 누락·통계코드 오류, 수집 범위 확장 중 안내 등 |
| 60일 뒤 자동 실행 중단 | 공개 저장소는 60일간 변경이 없으면 예약 실행이 멈춤. 매일 데이터가 커밋되면 해당 없음. 멈췄다면 Actions 탭에서 다시 Enable |
